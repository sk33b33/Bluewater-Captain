# Bluewater Captain — Claude Code Project Kit

This package is a build brief and working set of project instructions for Claude Code. It describes a staged 3D maritime career game built around licensing, ship progression, and port-to-port missions.

## How to use
1. Extract this ZIP into a new, empty project folder.
2. Open that folder in Claude Code.
3. Ask Claude Code: **“Read `CLAUDE.md` and all relevant project instructions. Begin Stage 0 only. Inspect the environment, propose the architecture, and create the Stage 0 deliverables. Do not jump ahead to later stages.”**
4. Review and test each stage before authorizing the next one.

## Important
- This is a project specification and agent/skill instruction kit, not a prebuilt game.
- The game must be built in stages. Do not attempt the full open-world game in one pass.
- Start with a small, polished playable vertical slice. Expand the world and content only after the core sailing loop works.
- Use original or properly licensed assets. Famous ships such as Titanic and the Black Pearl are requested as aspirational unlockables, but their names, designs, likenesses, logos, and associated IP may be protected. Do not reproduce them commercially without checking rights. Use clearly original fictional equivalents by default.
- Prefer a maintainable, playable build over placeholder-heavy promises. If a feature cannot be completed in the current stage, document it and leave a clean extension point.
