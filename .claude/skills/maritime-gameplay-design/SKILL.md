# Skill: Maritime Gameplay Design

- Make each license teach a new, observable skill and unlock a clear vessel/missions tier.
- Use fictional in-game license names and make clear they are not official real-world credentials.
- Every mission must define origin, destination, required license/vessel, objectives, failure conditions, reward, and scoring.
- Keep navigation readable: clear markers, compass/heading, route information, warnings, and arrival zone.
- Vessel classes must differ through handling and constraints, not only appearance.
- Make docking a learnable skill with feedback rather than a random pass/fail event.
- Tie waves, wind, visibility, and currents to gameplay only when the player can understand their effect.
- Build one complete mission before multiplying mission types or ports.
